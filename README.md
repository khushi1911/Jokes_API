# Jokes API

A simple REST API project that provides **different jokes through HTTP operations**. The project demonstrates how to create and interact with an API using Node.js and Express.js.

## Features

* Create and manage jokes
* Retrieve jokes through HTTP requests
* Perform different HTTP operations
* RESTful API structure
* JSON-based API responses

## Tech Stack

* **Backend:** Node.js, Express.js
* **Language:** JavaScript
* **Data Format:** JSON

## HTTP Operations

| Method          | Operation      |
| --------------- | -------------- |
| `GET`           | Retrieve jokes |
| `POST`          | Add a new joke |
| `PUT` / `PATCH` | Update a joke  |
| `DELETE`        | Delete a joke  |

## How It Works

1. The client sends an HTTP request to the API.
2. The Express server processes the request.
3. The requested operation is performed on the joke data.
4. The API returns a JSON response to the client.

## How to Run

1. Clone the repository.
2. Install the dependencies:

```bash
npm install
```

3. Start the server:

```bash
node index.js
```

4. Use **Postman** or another API client to test the endpoints.

## Purpose

This project was created to practice **REST API development, HTTP methods, Express.js, CRUD operations, JSON data, and API request/response handling**.
